# 0.2 验证记录

## 自动检查

`npm run check`：构建与 9 项 Node 测试通过。

- 276 个节点、13 处选择：跳转、条件、立绘、场景、音乐资源有效；缺失跳转直接报错。
- 枚举 4,653 个不同选择 / 终点状态、2,988 个终点状态组合；覆盖凯、莉拉、独行与坏结局，未发生串线。
- 每个可达选择分支：保存后重载与原状态一致，回退精确恢复分支前状态，包括关系、线索、立绘、位置、声音和历史。
- 验证先前行为解锁选项、超过 20 条历史保留、坏结局停止、损坏与版本不兼容存档拒绝替换、旧数据原样保留、跨周目 CG 独立、存储失败明确报告。

## 浏览器实测

开发环境：Windows Edge，使用真实页面操作，无注入剧情状态。

- 新游戏到共同线分歧；记住编号后获得对应线索与后续选项。
- 390 × 844 手机布局、多选项、双人立绘、菜单与存档。
- 800 × 900 布局与阅读控制；默认桌面标题与阅读画面。
- Enter 确认选项、刷新恢复自动存档、手动保存、快进遇未读暂停、自动遇选择暂停。
- 凯路线达到“有人走出了名单”，正确回顾保存记忆与坦白芯片；返回本次游玩的共同线检查点。
- 莉拉路线达到“留下可以追问的证据”，完整批准链选项由两份证据解锁，收尾回顾对应实际发布方式。
- 坏结局“调查在这里中止”停止推进；返回签署前，线索与画面一致。
- 390px 四选项、28px 长对白、按钮聚焦时的 A 快捷键均可使用。
- 独行路线达到“把过去留给下一次自己”，结尾显示自取名字获得档案副本与独自备份的实际选择。
- 三路线及坏结局完成后回忆画廊显示 9 幅解锁、3 段路线体验；重新开始仍保留。读取分歧前手动存档恢复共同线与 3 条线索。
- 1440 × 900 章节收尾检查通过；浏览器控制台无捕获到的警告或错误。

发布仍使用原有 GitHub Pages 的 `main` 根目录，推送后由平台构建上线。
