# 首次玩家试玩记录

状态：待招募与执行。以下是模板，不是已经完成的用户研究。

招募 5 名未接触项目的玩家，覆盖手机与桌面。让玩家从新游戏开始，自由选择路线，观察时不解释剧情或提示“正确”选项。取得本人同意后才录屏，无需收集真实姓名或联系方式。

开场：“请按照自己的想法玩到一个章节终点。任何时候都可以停止。”

记录首次困惑的对白或选项、时间、玩家原话；记录长时间停留、误触、尝试回退、退出的位置。中途不要求持续讲解，避免干扰阅读。

完成或退出后询问：

1. 你刚才想完成什么？
2. 哪一次选择产生了什么后果？
3. 你还想追查哪个问题？为什么？
4. 哪个地方想停下或不想继续？

目标：至少 4 人能用自己的话说清目标、一次选择的后果，以及想继续追查的悬念。不能用自动化测试代替。若未达到，按首次困惑位置调整信息顺序，再以新玩家复测。

问题反馈请附设备、浏览器版本、此前选项、预期与实际结果。可附导出存档；提交前检查是否愿意公开自己的选择记录。
